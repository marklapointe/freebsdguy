# Top 3 Desktop Environments for FreeBSD

While many people think of FreeBSD as a server-only OS, it can also be a fantastic desktop OS! Here are my top 3 choices for desktop environments on FreeBSD.

## 1. KDE Plasma

KDE Plasma is arguably the most feature-rich DE available on FreeBSD. It is highly customizable and looks stunning.

To install it, run:
```bash
pkg install xorg kde5
```

## 2. XFCE

If you prefer a more lightweight experience, XFCE is the way to go. It is incredibly stable and fast on FreeBSD.

To install it, run:
```bash
pkg install xorg xfce
```

## 3. MATE

MATE provides a classic desktop experience that is easy to use and very familiar to users of older GNOME versions.

To install it, run:
```bash
pkg install xorg mate
```

## Conclusion

No matter what your preference is, FreeBSD has something for everyone. Give these DEs a try and let me know which one you like best!
