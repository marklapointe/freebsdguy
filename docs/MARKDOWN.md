# Markdown on MDWeb

Posts are `.md` files with YAML frontmatter:

```yaml
---
title: My post
summary: One-line tease
date: 2026-07-30
author: you
pinned: true
---
```

## Supported (demo posts)

| Feature | Demo post |
|---------|-----------|
| Headings, lists, tables, tasks | `kitchen-sink-markdown` |
| Fenced code | `code-from-the-terminal` |
| KaTeX math | `math-for-the-rest-of-us` |
| Mermaid diagrams | `diagrams-over-coffee` |
| Theme flavor prose | `crt-dreams-and-amber-glow` |

Shipped demos seed into the posts directory **only if missing** (never overwrite your edits).

Images: store under the posts `images/` tree and reference via the app’s image URLs / picker.
