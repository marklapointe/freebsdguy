## Why Playwright is on the agent, not FreeBSD

- FreeBSD packages on the test host include **Firefox**, not a Chrome/Chromium browser suitable for Playwright’s default stack.
- Agent workstation has **Google Chrome 150** and can reach `172.16.176.133` with ~2ms RTT.
- Package-installed Node app on FreeBSD + browser automation from Linux is the realistic split.
