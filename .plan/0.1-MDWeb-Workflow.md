# MDWeb Workflow

## Task Management
All tasks are tracked in the implementation backlog files using the standardized table format.

### Standardized Task Table Format
| ID | Task | Status | Assigned To | PR/Reference |
|----|------|--------|-------------|--------------|

### Statuses
- `TODO`: Task is ready to be worked on.
- `IN_PROGRESS`: Task is currently being worked on.
- `BLOCKED`: Task cannot proceed due to external factors.
- `DONE`: Task is completed and verified.

## Protocol
1. **Claiming a Task**: Set your name in the `Assigned To` column and change status to `IN_PROGRESS`.
2. **Completing a Task**: Update status to `DONE` and provide a reference (e.g., commit hash or PR link).
3. **Adding Tasks**: New tasks should be added to the backlog with a `TODO` status.
