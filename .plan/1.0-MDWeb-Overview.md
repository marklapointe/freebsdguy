# MDWeb Project Overview

## Summary
MDWeb is a personal website stack designed for FreeBSD, featuring a Markdown-based blog with AI-powered summarization capabilities. It aims to provide a lightweight, self-hosted solution for developers to share their thoughts and projects.

## Architecture
The application follows a traditional client-server architecture:

- **Frontend**: A single-page application built with React, Vite, and Tailwind CSS. It communicates with the backend via a REST API.
- **Backend**: A Node.js Express server written in TypeScript. It handles authentication, post management, and integration with AI services (Ollama/OpenAI).
- **Storage**: Markdown files are used for blog posts, and JSON files are used for configuration and user data. Images are stored in a dedicated directory.

## Key Features
- **Markdown-based Blogging**: Write posts in Markdown and have them rendered on the site.
- **AI Integration**: Automatically generate summaries and enhance post content using Ollama or OpenAI, featuring a preview-before-apply workflow.
- **Theme Management**: Support for multiple themes and user-specific preferences.
- **Customizable Branding**: Support for site-specific logos and customizable site name text colors via the theme system.
- **Advanced Image Management**: Integrated image manager with drag-and-drop uploads, configurable pagination, and automated deduplication using MD5 checksums.
- **TUI Management Tool**: Console-based application (`npm run setup`) for site configuration, admin setup, and directory management.
- **Pre-flight Checks**: Automated startup verification of configuration, security secrets, and required directories, with interactive auto-fix capabilities.
- **FreeBSD First**: Designed to be deployed on FreeBSD with dedicated startup scripts and port definitions.

## Platform Details
MDWeb is optimized for FreeBSD:
- **Deployment**: Managed via a `Makefile`.
- **Service Management**: Includes an `mdweb.rc` script for FreeBSD's `rc` system.
- **Packaging**: Includes a `ports/` directory for integration with the FreeBSD Ports Collection.
